# Первая встреча — бэкенд

Игра-тренажёр для менеджеров по продажам 2GIS. Настоящие аккаунты (логин/пароль),
прогресс и лидерборд хранятся в базе данных на сервере, звонки к ИИ идут через сервер
(ключ Anthropic никогда не попадает в браузер).

## Стек

- Node.js + Express — сервер и API
- SQLite (better-sqlite3) — база данных (файл `data.sqlite`, создаётся автоматически)
- bcryptjs — хеширование паролей
- express-session — сессии по cookie
- Простой фронтенд на HTML/CSS/JS в `public/`, отдаётся тем же сервером

## Локальный запуск

```bash
npm install
cp .env.example .env
# впиши в .env свой ANTHROPIC_API_KEY (console.anthropic.com) и любой SESSION_SECRET
npm start
```

Открой http://localhost:3000 — сможешь зарегистрироваться и играть.
Без `ANTHROPIC_API_KEY` регистрация/лидерборд работают, а звонки и встречи — нет
(сервер вернёт понятную ошибку вместо падения).

## Деплой на Render (рекомендуемый вариант, есть бесплатный план)

1. Залей этот код в свой репозиторий на GitHub (Render разворачивает именно из репозитория).
2. На render.com: New → Web Service → подключи репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. В разделе Environment добавь переменные:
   - `ANTHROPIC_API_KEY` — твой ключ с console.anthropic.com
   - `SESSION_SECRET` — любая длинная случайная строка
   - `NODE_ENV` = `production`
6. Деплой запустится автоматически. Render выдаст постоянный публичный URL вида
   `https://твой-проект.onrender.com` — вот эту ссылку и отправляешь в 2GIS.

**Важно про базу данных:** на бесплатном плане Render файловая система не персистентна
между редеплоями — то есть `data.sqlite` может обнулиться при следующем деплое.
Для пилота/демо это обычно не критично, но если нужна надёжность — на Render можно
подключить бесплатный PostgreSQL и заменить SQLite (это отдельная небольшая доработка,
могу сделать, когда дойдёт до реального запуска).

## Деплой на Railway (альтернатива, тоже просто)

Аналогично: подключаешь GitHub-репозиторий, Railway сам определяет Node.js проект,
задаёшь те же переменные окружения (`ANTHROPIC_API_KEY`, `SESSION_SECRET`) — и он выдаёт
публичный URL.

## Структура проекта

```
server.js          — весь бэкенд: авторизация, сохранение прогресса, лидерборд, прокси к Claude
public/index.html  — фронтенд игры (карта дня, звонки/встречи, дашборд, лидерборд)
package.json       — зависимости
.env.example       — пример переменных окружения (скопировать в .env)
```

## API

| Метод | Путь | Описание |
|---|---|---|
| POST | /api/register | Регистрация {username, password} |
| POST | /api/login | Вход {username, password} |
| POST | /api/logout | Выход |
| GET | /api/me | Текущий пользователь (или null) |
| GET | /api/state | Сохранённый прогресс текущего пользователя |
| POST | /api/state | Сохранить прогресс {state} |
| GET | /api/leaderboard | Общий рейтинг всех игроков |
| POST | /api/chat | Прокси к Claude API (нужен ANTHROPIC_API_KEY на сервере) |
